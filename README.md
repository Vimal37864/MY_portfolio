# Vimal Balaji V R — Full Stack Portfolio

Modern, responsive full-stack developer portfolio built with React.js, Tailwind CSS, and Python Flask.

---

## 📁 Repository Structure

```text
├── frontend/             # React.js + Tailwind CSS client
│   ├── public/           # Static assets, HTML template, favicon, manifest
│   ├── src/
│   │   ├── components/   # React components (Header, Projects, Experience, Certifications, etc.)
│   │   ├── data/         # Portfolio data (projects, skills, experience)
│   │   ├── images/       # Profile photo and media assets
│   │   └── resume/       # PDF resume (vimalbalaji_resume.pdf)
│   ├── package.json      # Frontend dependencies & scripts
│   └── tailwind.config.js# Tailwind configuration
│
├── backend/              # Python Flask RESTful API server
│   ├── app.py            # Flask application & API routes
│   ├── requirements.txt  # Python backend dependencies
│   └── README.md         # Backend documentation
│
└── README.md             # Project documentation
```

---

## 🚀 Quick Start

### 1. Frontend (React.js)

```bash
cd frontend
npm install
npm start
```
The application will be live at `http://localhost:3000`.

### 2. Backend (Python Flask)

```bash
cd backend
pip install -r requirements.txt
python app.py
```
The backend API server will run at `http://localhost:5000`.
